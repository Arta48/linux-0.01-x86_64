# Linux 0.01 (x86_64 Edition)

A modern reimplementation of Linus Torvalds' historic **Linux 0.01** kernel (released September 17, 1991), rewritten for the **x86_64 (AMD64 / Long Mode)** architecture.

---

## 📌 О проекте

Оригинальное ядро Linux 0.01 представляло собой компактный монолит (~8 000 строк кода), глубоко завязанный на аппаратные особенности микропроцессора Intel 80386:
* Аппаратное переключение контекста задач через дескрипторы **TSS** и инструкцию `ljmp`.
* Сегментная модель памяти с изоляцией процессов через **LDT** и доступ к пользовательской памяти через регистр `%fs`.
* 32-битный двухуровневый пейджинг с жестким ограничением в **8 МБ ОЗУ**.
* Инструкции `pushal` / `popal` для сохранения состояния регистров в прерываниях.

В 64-битном режиме (**Long Mode**) архитектуры AMD64 большинство этих механизмов были **аппаратно удалены** или заблокированы. Этот проект — не просто адаптация флагов компилятора, а поэтапное архитектурное переосмысление раннего ядра под современную 64-битную платформу с сохранением оригинального духа, минимализма и алгоритмов Линуса.

---

## 🏛️ Архитектурные отличия

| Компонент | Оригинальный Linux 0.01 (1991, i386) | Linux 0.01 x86_64 |
| :--- | :--- | :--- |
| **Режим CPU** | 32-битный Protected Mode | 64-битный Long Mode |
| **Пейджинг** | 2-уровневый (`pg_dir` -> `pg0`/`pg1`, 32-бит) | 4-уровневый (`PML4` -> `PDPT` -> `PD` -> `PT`, 64-бит) |
| **Переключение задач** | Аппаратное через TSS (`ljmp *TSS`) | Программное через стек ядра (`switch_to` в ассемблере) |
| **Прерывания (IDT)** | 8-байтовые дескрипторы, `pushal`/`popal` | 16-байтовые дескрипторы, ручное сохранение `%r15..%rax`, `iretq` |
| **Консоль** | Только текстовая память VGA (`0xB8000`) | VGA (`0xB8000`) + Последовательный порт COM1 (`0x3F8`) |
| **Системные вызовы** | Медленный шлюз прерывания `int 0x80` | Быстрые инструкции `syscall` / `sysret` |
| **Память** | 8 МБ ОЗУ (hardcoded) | 128 МБ+ динамического управления (`mem_map`) |

## 🗺️ Дорожная карта разработки

- [x] **Stage 1: Bootstrapping & Long Mode Entry**
  - Поддержка стандарта загрузки Multiboot.
  - Инициализация 4-уровневых таблиц страниц (PML4, PDPT, PD) с Huge Pages (2 МБ).
  - Включение PAE, LME (Long Mode Enable), переход в 64-битный режим.
  - Двойной видеодрайвер: текстовый буфер VGA `0xB8000` и COM1 для вывода логов в терминал.
- [x] **Stage 2: Interrupts, Exceptions & Hardware Timer**
  - Создание 16-байтовых шлюзов 64-битной IDT.
  - Обработка исключений процессора (0..31) без использования несуществующего `pushal`.
  - Перепрограммирование контроллеров прерываний PIC 8259 на векторы `32..47`.
  - Настройка таймера Intel 8253 PIT на 100 Гц (`HZ = 100`) и ведение счетчика `jiffies`.
- [x] **Stage 3: Physical & Virtual Memory Management**
  - Определение границ ядра через экспортируемый символ компоновщика `_end`.
  - Аллокатор физических страниц памяти на 128 МБ (`get_free_page`, `free_page`).
  - Функция динамического 4-уровневого маппинга страниц `map_page()`.
  - Перехват Page Fault (#PF) с чтением адреса сбоя из регистра `CR2`.
- [x] **Stage 4: Processes & Preemptive Multitasking**
  - Структура задачи `task_struct` и объединение со стеком ядра `union task_union`.
  - Программное переключение контекста в `kernel/switch.S` (подмена `%rsp` и регистров ABI).
  - Оригинальный алгоритм планировщика Линуса (`counter` / `priority`).
  - Вытесняющая многозадачность по тикам таймера (`do_timer`).
- [x] **Stage 5: System Calls & Ring 3 User Space**
  - Настройка MSR-регистров для аппаратных вызовов `syscall` / `sysret`.
  - Изоляция адресного пространства через индивидуальные таблицы страниц (CR3).
  - Переход в пользовательский режим (Ring 3) и исполнение первого процесса `init`.

## 🛠️ Сборка и запуск

### Требования (Arch Linux)
```bash
sudo pacman -S --needed base-devel qemu-system-x86
```

### Сборка и запуск одной командой
```bash
./compile.sh
```

Либо через `make`:
```bash
make clean
make
make run
```

## 📂 Структура проекта

```text
.
├── boot/
│   ├── boot.S          # 32-битный вход, инициализация таблиц страниц, прыжок в Long Mode
│   └── linker.ld       # Скрипт компоновщика ядра (ELF32-контейнер с 64-битным кодом)
├── init/
│   └── main.c          # Главная точка входа ядра (main)
├── kernel/
│   ├── asm.S           # Низкоуровневые заглушки прерываний (ISR)
│   ├── console.c       # Драйвер вывода (VGA 0xB8000 + Serial COM1)
│   ├── sched.c         # Планировщик Линуса и управление задачами
│   ├── switch.S        # Программное переключение контекста (switch_to)
│   └── traps.c         # Настройка IDT, PIC 8259, PIT-таймера и обработчик прерываний
├── mm/
│   └── memory.c        # Менеджер физических фреймов и 4-уровневый пейджинг
├── include/
│   ├── asm/
│   │   └── io.h        # Порты ввода-вывода (inb, outb)
│   └── linux/
│       ├── mm.h        # Заголовок менеджера памяти
│       ├── sched.h     # Заголовок планировщика и task_struct
│       ├── traps.h     # Заголовок IDT и trap_frame
│       ├── tty.h       # Заголовок консоли и printk
│       └── types.h     # Базовые целочисленные типы ядра
├── compile.sh          # Скрипт быстрой пересборки и запуска
├── Makefile            # Правила сборки
└── README.md
```
